# Creator Agent identity

The angular C takes its shape from a folded index card. Use the standalone mark for the app and the horizontal logo wherever readers first encounter the name.

| Files | Use |
| --- | --- |
| `app-icon.svg`, `app-icon-1024.png` | Sage app tile with transparent corners. The SVG is editable. |
| `windows.ico` | Windows app, taskbar and tray. Contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 px frames. |
| `favicon.ico`, `touch-icon-180.png` | Browser tabs and Apple home-screen bookmarks. The touch icon uses an opaque square for system masking. |
| `mark.svg`, `mark-ink.png`, `mark-sage.png` | Editable mark and transparent raster exports for diagrams, documents and slides. |
| `wordmark-ink.png`, `wordmark-sage.png` | Transparent horizontal logos. Choose ink for light surfaces and sage for dark surfaces. |
| `studio-cover.png` | 1200 × 630 title card for project notes, presentations and link previews. |
| `overview.png` | Visual reference with the palette and actual-size icon examples. |

Keep the icon square. Give the freestanding mark or horizontal logo clear space of roughly one quarter of the mark’s height on each side. Use the supplied small frames for placements of 24 px or less. The small frames omit the thin fold. When the name already appears beside the icon in the UI, use an empty image alt attribute so a screen reader announces the name once.

The palette comes from the studio’s existing theme. Ink is `#141312`, sage is `#8FC4A6` and paper is `#F4F3EE`. The horizontal lettering uses Segoe UI Semibold.

## Source and exports

Created November 11, 2026. The starting silhouette was generated with ImageGen for this project from a brief for a single-color, folded-index-card C. Its edges were straightened on a 96 × 90 grid for the SVG master. PNGs, native icon frames and cover art derive from that geometry. `SHA256SUMS.txt` records the pack contents.
