## Reconciliation decisions made in this kit

1. Preserve the broader product while introducing a thesis-first delivery order. Earlier commercial/desktop/optimization work is deferred visibly, not removed.
2. Add the three-arm comparison without erasing the earlier structured/open-ended baseline. Propose a separate study to control workload; final priority/sample size remains open.
3. Replace an unconditional “human approves every selected idea” rule with a mode-dependent rule. Human-in-loop can require selection approval; autonomous trials can select only within their preauthorized packet.
4. Prevent “auto-approve” from meaning an agent grants itself authority. Covered actions use standing policy; uncovered decisions wait or stop.
5. Make non-code/human-led recommendations first-class outcomes and keep software-opportunity scores out of cross-option suitability totals.
6. Resolve local-first versus hosted-control tension with local deployment first and hosted control as an explicit mode. API inference remains an external data flow.
7. Treat all example costs, percentages, sample counts, model prices, and rollout settings as proposals, not approved or empirically supported values.
8. Treat historical framework/authentication snippets as dated implementation guidance; verify current official documentation before coding them.
9. Do not import C++ trading-system requirements, personal school repositories, or the senior-project presentation date into this project.

## Using the archived references

The reference files preserve earlier detail and research leads. Their headers explicitly mark them archived. Use the canonical root/context documents for present scope and precedence. Do not auto-execute the archived 48-step sequence or load the entire research guide into each agent call.

The research guide contains previously curated sources; this kit does not re-verify every scholarly link or adopt each proposed metric as validated. Before using a source for a thesis claim, open the original paper, check the specific passage/method, and record its limits. Never cite an agent's summary as if it were the underlying study.
