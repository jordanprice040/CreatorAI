# Search APIs for Creator Agent

Research access date: **November 10, 2026**. USD unless marked GBP. This is a documentation review, not an API quality test, contractual clearance, sign-up, purchase, or activation.

**Recommendation:** start with **Tavily Researcher Free, Basic Search**, subject to written clarification of thesis publication and durable result retention. Keep PAYGO off. **Mojeek Business** is the strongest documented alternative for permanent result storage, but GBP pricing requires a settled dollar funding/reservation rule. **Brave Search prepaid** remains a conditional third choice because its published default terms conflict with the intended storage/evaluation workflow. None is unconditionally cleared for this entire use case.

## Reading the evidence

Every external factual statement below has a linked source reference. **Every source was accessed November 10, 2026**; the register gives that date separately for each source and reports the page date, or “no date shown.” A search engine's inferred publication timestamp is not treated as a document's effective date. Some pages were obtained as extracted excerpts, which cannot establish that an unmentioned clause does not exist. Failed extractions are preserved in the source receipt.

“Not stated” means not established in the public material reviewed, not that a provider prohibits or permits it. “Possible” is a conditional fit judgment. “Good” would require the important billing, preservation, AI-use and research questions to be resolved; no provider earns that unconditional rating here. Technical AI support is distinguished from contractual permission. Inference and recommendations are explicitly identified.

The supplied workload, architecture, $20 lifetime allowance and thesis context are **owner-provided assumptions**. No participant, institution, protocol approval, remaining budget, existing provider-account entitlement, or current promotional eligibility was verified. Local code inspection found `packages/broker/src/public-search.ts`: the existing Brave adapter requests 10 raw Web results, requires 1–5 approved domains, and does not implement the proposed broad any-public-host search behavior. This report does not change it.

## Top three and exact plans

These are **my fit judgments**, not provider endorsements or activation approvals.

1. **Tavily — Researcher, Free; explicit Basic Search.** Best $0-first development choice: 1,000 monthly credits, no card, one credit per Basic request. Pin `search_depth=basic`, turn automatic parameter selection off, request at most 10, and disable generated answers/raw content because the application fetches its own evidence. Never allow an automatic upgrade to Advanced. [Pricing][T1], [request reference][T3]

   **Before activation for the full thesis workflow:** obtain confirmation that an individual academic owner qualifies under internal-business-purpose wording; retain raw ranked results/snippets and audit metadata indefinitely; publish aggregate studio comparisons and necessary examples despite the performance-information disclosure restriction; and clarify which query data is used for training when AI Functionality is disabled. API integration with AI Customer Applications is expressly contemplated, but that does not erase the other clauses. [Terms][T2]

2. **Mojeek — Business PAYG, £3/1,000; not Startup.** Best documented permanent-record option: Business/Enterprise explicitly have indefinite storage rights; Startup permits only one-hour same-user caching. Business offers 10 QPS and 40 results/request; this app should still request 10. There is no automatic payment and no minimum commitment advertised. [Plan FAQ][M1]

   **Before activation:** confirm the initial deposit, card requirement, whether balance exhaustion stops every call, query-only 90-day retention scope, permitted third-party LLM grounding, and publication of aggregate comparisons/examples. Explain that results discover sources and publisher pages are separately fetched: the non-search-use clause limits Data to source discovery. Settle GBP-to-USD prepaid valuation, fees/taxes and reservation rules before any paid dispatch. A local provenance catalog is not intended as a competing web search index, but that is **my interpretation**; obtain confirmation against the index prohibition. [Terms][M2]

3. **Brave — current Search prepaid plan, Web Search endpoint; a storage/research rights amendment is essential.** The current unified Search offer is $5/1,000, includes Web and LLM Context, $5 monthly promotional credit, and 50 requests/second. Card required. Do not use obsolete $3-plan or 2,000-free-query descriptions. [Current pricing][B1], [product FAQ][B6]

   **Before activation:** secure the exact plan/order terms granting permanent result storage, third-party LLM inference and thesis evaluation/publication. Default §3(b) limits storage to transient operation and prohibits using results to evaluate/benchmark/improve AI models or services. “Storage rights available” on a marketing page does not identify a qualifying self-service license. Ask which signed/order clause overrides each restriction, and whether rights survive account termination. [Terms][B2], [FAQ][B6]

   **Endpoint choice, my inference:** Web Search matches this app's URL/title/snippet → guarded fetch → immutable passage design. Brave's statement that LLM Context is for machines describes a more convenient extraction product; it does not, by itself, establish that Web Search is banned as source discovery for an AI application. LLM Context returns pre-extracted context and source metadata, considers up to 50 results, and adds no need the supplied pipeline has. Confirm contractual endpoint eligibility rather than silently switching the adapter. [Web reference][B4], [Context reference][B5]

**Why Exa, You.com and Linkup are not top-three winners today:** Exa has useful free credits and prepaid/key controls, but broad copying restrictions and query-training permissions weaken the preservation/privacy fit. You.com's current and older free-credit offers disagree, and durable retention/cap behavior needs confirmation. Linkup's pricing is attractive but the fetched terms page returned only a shell: this review cannot clear it. [Exa terms][E3], [Exa privacy][E4], [You current][Y1], [You older offer][Y5], [Linkup terms][L4]

## A $20-total spending plan

**Recommended now:** use **zero paid dollars** for search. Conditional on the above rights clarification, Tavily Researcher provides up to 1,000 Basic searches per month without a card; 10–40 queries/run implies 25–100 runs/month before retries. This is arithmetic from the workload assumption, not a provider throughput promise. The paid fallback is **not automatic**. [Allowance and credit unit][T1]

If the free tier ends, the dollar-denominated, fixed-price fallback to seek is **Brave Search prepaid with confirmed storage/evaluation rights**: $20 buys **4,000 paid requests before tax**, plus whatever monthly promotional credits are actually granted. Keep recharge off and buy only from the remaining shared allowance. If a rights add-on, minimum purchase, fees or taxes would exceed the remaining allowance, stop. Tavily Basic PAYGO would buy 2,500 paid requests before tax for $20, but a provider-enforced $20 lifetime cap was not confirmed; do not call it a prepaid hard-cap alternative. [Brave price][B1], [credit terms][B7], [Tavily price][T1]

Mojeek Business is the stronger storage fallback, but **an exact number of queries for US$20 is not stated**: the tariff is £0.003/request. For an actually purchased GBP balance `B`, the nominal count is `floor(B / 0.003)`. Dollar funding must include the actual conversion, fees and tax. No exchange rate is guessed. [Tariff][M1]

**Application recommendation:** reserve the configured paid tariff even while free promotional credits exist unless the application can deterministically enforce that only free balance can be consumed. Count a second dispatched attempt as a new reservation; an ambiguous timeout remains reserved until reconciled. Cancellation does not prove a remote request was unbilled. Keep app lifetime remaining-budget enforcement separate from provider monthly quotas. These are proposed implementation rules, not existing verified behavior.

Unknown error billing is unknown even if 429 is commonly unbilled elsewhere.

## Terms and privacy findings that can change the decision

**API metadata and independently fetched evidence are separate rights questions.** No reviewed provider establishes a universal right to copy all linked publisher pages, store them forever or republish passages. Several expressly leave third-party content rights with publishers. The proposed guarded fetcher establishes technical admission, not copyright permission. **My recommendation:** store only permitted passages, retain publisher/license/access metadata, and obtain permission or an applicable legal basis for each retained/reproduced class of content. Do not infer an academic exemption or “short quote always allowed.” [Brave third-party-content clause][B2], [Serper Data License][S2], [Firecrawl third-party content][F3]

**Brave — concrete default prohibition.** Default terms restrict persistent results, derivative works and AI evaluation/benchmarking/improvement; delete results at termination. Attribution is optional, with rules if used. A plan/order with appropriate rights could override defaults; neither endpoint marketing nor free credit proves that amendment. API queries are account-billed, retained up to 90 days; enterprise ZDR is separate. The privacy notice says query data is excluded from the DPA scope. [Terms][B2], [Privacy][B3]

**Tavily — thesis disclosure is the unusual blocker.** Services restrictions include disclosing performance information/analysis to third parties and competing with Tavily; Output is excluded from the Services definition. This does not automatically ban an evidence-based studio thesis, but it prevents an unconditional promise that publication is permitted. Internal business wording and permanent output storage need confirmation. AI Functionality terms permit Tavily/third-party providers to retain and train on inputs/outputs and require independent verification/human suitability review; do not promise a wholly unattended final decision path satisfies these requirements. No numeric query-retention period, default region or public ZDR/DPA eligibility was established. [Terms][T2], [Privacy][T5]

**Exa — storage and privacy are not cleared by its free credits.** The broad restriction on copying/publishing information from the Services has an express-permission exception; infer neither that all API archival is forbidden nor that marketing silently overrides it. Get written authorization for persistent audit records and examples. Competitive-product restriction also applies. Privacy policy allows Query Data for training/fine-tuning and advises against personal information in queries. Enterprise ZDR is available, but its self-serve $12,000 annual commitment is outside this budget. [Terms][E3], [Privacy][E4], [ZDR][E7]

**Kagi — direct evidence/evaluation mismatch.** AI answering is explicitly permitted; persistent Results databases and systematic harvesting for evaluation datasets are prohibited under default terms. That is more than a training-only ban. Queries may be temporarily logged separately from accounts; exact lifetime is not stated. API terms say a full DPA is being finalized and signed processing terms can be requested. A custom written exception is necessary for this application's preserved result/evaluation corpus. [API terms][K2]

**Mojeek — distinguish the plans.** Startup expressly prohibits compiling/copying/storing Data other than the one-hour cache. Business/Enterprise storage rights are indefinite according to the FAQ; no attribution is required per that FAQ. A search index built from Data is prohibited, and non-search use is limited to finding sources. The API page promises 90-day retention, DPA with no subprocessors and ZDR on request; the general consumer privacy page instead describes indefinite nonidentifying logs. Treat API-specific 90 days as the applicable product claim and confirm its contractual scope. [Plans/FAQ][M1], [Terms][M2], [General privacy][M6]

**Serper and SerpAPI — vendor access does not settle publisher rights.** Serper permits downloads for as long as the use case needs, preserves attribution/notices, is unaffiliated with Google, and calls itself B2B only. Personal academic eligibility remains an explicit question. SerpAPI legal/privacy terms say search data lasts 31 days; ZeroTrace and DPA by request are documented, but affordable plans do not include ZeroTrace. Its legal shield covers lawful collection within its scope, not every downstream reuse. Scraped Google results from these products do not independently corroborate one another. [Serper terms][S2], [Serper privacy][S3], [SerpAPI legal][A2], [plans][A1]

**You.com — privacy improvement, unresolved retention/license scope.** Privacy policy says prompts/files/outputs are not used to train its or third-party models unless separately opted in. General terms forbid competing products and exempt API-key access from the general automation restriction. Those clauses do not establish permanent result archival or public research rights. Enterprise ZDR/DPA are advertised. Current $10 free credit and older $100 offer conflict; never budget from the larger one without actual account confirmation. [Privacy][Y4], [Terms][Y3], [Billing][Y2], [Pricing][Y1], [Older offer][Y5]

**Firecrawl — AI product, unresolved commercial-use wording.** Terms describe an AI data tool but prohibit commercial use except as expressly authorized. Confirm what the chosen plan authorizes before distributing or monetizing the app. The general privacy policy permits caching/indexing and advertising-related processing, identifies US servers, and gives no fixed query-retention duration. ZDR is enterprise/configuration dependent. Its search/source content is not automatically an evidence license. [Terms][F3], [Privacy][F4], [Pricing][F1]

**Linkup — incomplete legal retrieval is not permission.** The terms URL returned a shell with no operative text. Pricing advertises 4,000 free queries, not a confirmed monthly grant. Security docs say default processing can span US/EU/Canada/APAC, a DPA is available, and ZDR requires request; default query/result retention duration and complete training policy were not established. Do not use the privacy policy's six-month **website connection log** period as API-query retention. [Terms shell][L4], [Security FAQ][L3], [Privacy][L5], [Pricing][L1]

**Perplexity — Search does not inherit Sonar privacy guarantees.** The Search Addendum explicitly supersedes conflicting general terms, excludes inherited ZDR commitments, permits retention/copying/distribution of Search Data for business purposes and improvement, and excludes its confidentiality status. Personal Data submission needs express written authorization. Search Output is not owned by the customer. The public Search docs describe storing/feeding results to one's model, so this is principally a privacy/rights-scope issue rather than a documented blanket AI ban. General older FAQ ZDR statements are inadequate clearance. [Search Addendum][P3], [Search overview][P1]

**Microsoft — replacement is incompatible with evidence preservation.** Bing Search APIs retired August 11, 2025. Grounding is constrained to supported Microsoft services, exposes no raw content, requires exact reference display, prohibits storing/caching Output and prohibits training. “Never show raw results” does not waive its reference requirements. The Microsoft DPA does not cover grounding data. [Retirement][MS1], [Grounding docs][MS2], [Terms/display rules][MS3]

**Academic status is not a blanket carve-out.** No reviewed source supplied a universal exception for publishing a university thesis or redistributing publisher passages. No general ban on all academic research was established either. The strongest specific publication risks found are Brave AI evaluation, Kagi evaluation datasets and Tavily performance disclosure; Exa/You competing-product clauses may become relevant to later distribution. Do not label these as confirmed bans on the thesis as a whole. The cited terms establish restrictions; whether the exact proposed study falls within them remains a provider/legal clarification.

**The owner's report of $0 incremental CLI usage is accepted as context; this review did not audit those accounts.** Subscription access to an official client and an entitlement to a third-party raw-search API are different.

Brave explicitly claims an independent index with no Google/Bing fallback. Mojeek advertises its own global index and crawler. Exa describes an independent index and publishes retrieval evaluations. Serper identifies scraped Google data; SerpAPI has engine scraping and a distinct own-index preview. DuckDuckGo says most traditional links/images come from Bing. SearXNG's engines reuse upstream search sources. Remaining providers' complete engine mixtures were not established; do not call an undocumented mixture independent. [Brave FAQ][B6], [Mojeek][M1], [Exa FAQ][E8], [Serper][S2], [SerpAPI index preview][A5], [DDG sources][D1], [SearXNG][SX1]

- Exa's Brave comparison reports tests **July 29–August 2, 2026**, with shared query sets and an open benchmark repository. - You.com's **2025** report describes SimpleQA, FreshQA (July 28, 2025 dataset) and MS MARCO, with GPT-4.1 answering/judging. Exact article publication date was not shown in the retrieved content; the named year is the report label. [You methodology][Q2]

No live broad-interest/cross-field query evaluation was executed for any provider. Marketing “fresh,” “real-time,” or “best” is a provider claim, not a measured coverage/freshness guarantee. **My recommendation:** compare independent-domain yield, fetchable text, duplicated/syndicated results, contradicting evidence and useful passage yield on an owner-approved development set; keep held-out study tasks untouched.
