Set up this computer's studio

Creator Agent keeps its records in PostgreSQL and its settings, logs, backups and generated products in . Nothing here changes your existing databases or files unless a step says so.

1. PostgreSQL 18 folder

The app runs its own database with PostgreSQL 18. When this installer includes it, it is listed first and selected: setup copies it into the studio folder, and you need nothing else. Otherwise the app uses PostgreSQL 18 already installed on this computer (it downloads nothing): install it (the EDB installer or zip from postgresql.org), then enter its bin folder.

Websites approved for evidence

The starting list of websites for evidence, one host name per line (for example www.speedrun.com). Once you change evidence websites in the studio's Settings page, Settings is what counts: it applies without a restart and can also allow subdomains or any public website. Each fetch still needs a run that allows it. Saving here restarts the studio service.

Updates

Where updates come from

Creator Agent looks for new versions in a private GitHub repository's releases, using a token that can only read that repository. Nothing is checked until you save both and choose Check for updates. Builds are not code-signed yet, so Windows may warn about the installer; every download is checked against the SHA-256 its release names before it can be installed.
